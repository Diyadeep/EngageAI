AI Powered Online Learning Engagement Analyzer

EngageAI is an Artificial Intelligence based web application that monitors student engagement during online classes using OpenCV, MediaPipe, YOLOv8 and Machine Learning.

Face Detection

Detect whether the student's face is visible during the learning session.

Eye Tracking

Monitor eye movement and estimate the student's level of attention.

Phone Detection

Detect mobile phone usage using the YOLOv8 object detection model.

Drowsiness Detection

Identify drowsiness and lack of attention using facial landmarks.

Head Pose Detection

Estimate whether students are looking at the screen or away.

AI Suggestions

Generate personalized learning recommendations using Gemini AI.

Analytics Dashboard

View daily, weekly and monthly engagement reports with charts.

Teacher Monitoring

Teachers can monitor students and analyze engagement levels in real time.

About EngageAI

EngageAI is an AI-powered student engagement monitoring system developed for educational institutions. It uses Computer Vision, OpenCV, MediaPipe, YOLOv8 and Artificial Intelligence to monitor student attention, detect distractions, estimate engagement scores and generate detailed reports for teachers.
